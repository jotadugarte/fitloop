# ONVO Docs

> Documentación oficial para integrar ONVO: pagos, checkout, webhooks, autenticación, pruebas y referencia de API.

Este archivo enumera las páginas principales en formato Markdown para herramientas de IA, editores y agentes. La documentación humana está disponible en https://docs.onvopay.com.

- [Primeros pasos](https://docs.onvopay.com/getting-started.md): Flujo recomendado para integrar ONVO desde pruebas locales hasta producción.
- [Extensión para Magento](https://docs.onvopay.com/integrations/magento.md): Cómo instalar ONVO Pay en Magento.
- [SDK web](https://docs.onvopay.com/integrations/sdk.md): Cómo usar el SDK web de ONVO para pagos embebidos.

- [Inicio](https://docs.onvopay.com/index.md): Documentación oficial de ONVO para integrar pagos, checkout, webhooks y herramientas de desarrollo.

- [Marketplaces](https://docs.onvopay.com/payments/marketplaces.md): Cómo operar pagos en nombre de vendedores usando cuentas marketplace.
